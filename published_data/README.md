# Published numerical results

The three experiment folders contain book-level summaries, paired outcomes, statistical comparisons, and selection analyses. Figure source data and manuscript tables are provided separately.

Rates are proportions unless marked as percentages. Manuscript tables report differences in percentage points. Empty fields represent unavailable estimates. The legacy field name correct denotes agreement with the PersoNet reference label.

The main comparison uses four Holm-adjusted contrasts; the matched F comparison uses two. The deletion analysis reports a nominal GLM result and a descriptive DeepSeek estimate because one book supplied no eligible DeepSeek cases. The exact prompt text is in Prompt_protocols.txt; implementation details are in ../docs/STUDY_PROTOCOL.md.

The original literary corpus is obtained from the [PersoNet repository](https://github.com/Gorov/personet_acl23).
